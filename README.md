# my-high-school-sim
这是一个校园生活模拟器。
原型是东莞市东莞中学，东莞中学创建于1902年，原名“东莞学堂”，1950年改名为东莞中学。
校训：思考人生 追求真理 报效祖国 服务社会
办学理念：自主 和谐 共同发展
办学宗旨：对每一位学生的终身发展负责
游戏分为三个模式：沉浸、标准和速通，分别对应不同的游戏选择和游戏时长。

游戏中存在的一些不当之处，欢迎大家指正！
